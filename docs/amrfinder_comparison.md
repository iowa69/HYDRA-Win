# HYDRA-Win and AMRFinderPlus: the same genomes, the same database

Generated by `tools/compare_amrfinder.py`. HYDRA-Win does not run AMRFinderPlus (NCBI builds it for Linux and macOS only); it searches AMRFinderPlus's database with upstream Hydra's own BLAST code. This compares the two on the same FASTA files, the same database release and the same organism (`-O` is the organism HYDRA-Win assigned).

* AMRFinderPlus 4.2.7, database 2026-10-29.1, run with `-n --plus`.
* HYDRA-Win 0.7.0 (upstream Hydra 75ecbe8), database 2026-10-29.1, run offline through `hydra_win.core.analyse`.
* 48 genomes of 16 species (`tools/amrfinder_benchmark.tsv`), run on 2026-11-28.
